# Raw Dataset

SecureVision AI uses the CIFAR-10 dataset for image classification.

The complete dataset is not stored in this GitHub repository because
the dataset exceeds the 50 MB GitHub file limit specified in the
project guidelines.

The complete dataset will be downloaded using `download_data.py`.

## Dataset
- Name: CIFAR-10
- Task: Image classification
- Classes: 10

## Files
- `sample.csv` — small sample/metadata file for repository documentation
- `download_data.py` — script for obtaining the complete dataset
